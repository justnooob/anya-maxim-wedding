# Wishlist: согласование 19 скрытых подарков

04.11.2026. Продолжение PR #6 и текущей ветки. Все новые товары скрыты; одобрение не равно публикации.

## Реализация

- Используется существующий `POST /api/telegram/wishlist/approved-import`, общий `importApproved` и общий проверяющий WebP. Второго импортера или startup seed для партии нет.
- Preview сравнивает все записи, включая архивные/скрытые, по seed, модели, названию и URL. Несколько совпадений блокируют весь apply. Повторный импорт пропускает существующие и отклонённые записи, архивные не восстанавливает.
- Apply требует явного подтверждения и актуального SHA-256 плана: весь набор данных партии, версии/состояния строк и ссылки. Проверка и запись выполняются в одной транзакции под общей блокировкой админских изменений.
- Миграция 016 только добавляет nullable review_status, product_model и индекс. Старые строки сохраняют nullable статус и прежнюю публикацию. Старые миграции не переписаны.
- Новые карточки получают «На проверке». Есть отдельный фильтр партии, статусы, фото, цены, подробности, магазины, редактирование модели/описания/цены/категории/приоритета/ссылок/фото.
- Одобрение оставляет подарок скрытым. Публикация отдельная, с подтверждением. Отклонение сохраняется; есть фильтр и восстановление. Редактирование проверенной карточки возвращает её на проверку и скрывает до повторного решения.
- Замена выполняется в той же строке с сохранением seed, без второго подарка. При любой истории бронирования замена и изменение идентичности блокируются. Интерфейс предлагает скрыть старую карточку и создать отдельную, сохранив историю.
- Изменения проверяют version. Брони, старые подарки, RSVP, Telegram worker и уведомления не изменяются.
- Каждый admin endpoint проверяет подлинную подпись Telegram initData, срок и whitelist до БД. Отсутствующий/поддельный доступ получает 403; public API исключает pending/rejected.

## Реальный импорт

После доставки кода открой Telegram Mini App → Вишлист → «Проверить импорт 19 подарков».
Просмотри результат каждой позиции. Если нет конфликтов, отметь подтверждение и нажми «Добавить ... скрытых подарков».
После этого фильтр «Новая партия: 19 подарков» открывается автоматически. Проверь и одобри нужные карточки; публикуй отдельно.
Если совпадение или архивная запись неожиданны, apply не выполнять до разбора. Повторять импорт для восстановления удалённого подарка не нужно.

Агент не имеет подлинной Telegram-сессии организатора и не подделывает её токеном бота. Поэтому наличие кода/успешный push не считается доказательством живого импорта. Фактические deployment и import результаты фиксируются отдельно после проверок.
