# Восстановление paper airplane

1. Причина исчезновения: в visual polish я заменил существующие folding/flight состояния на departing/crossfade. CSS и бумажные поверхности остались, но перестали запускаться. Это была моя замена перехода, не проблема ассетов.
2. Восстановлено содержимое OpeningScene.tsx из Git commit 78cf31f (HEAD до polish). Единственное дополнение к исходному компоненту — data-paper-airplane на letter-rig для regression assertions. Старые CSS keyframes, фактура и трансформация самого письма сохранены без изменений. Новый crossfade удалён; остальные polish секции сохранены.

Последовательность: открытое письмо → кнопка «Дальше больше» → folding 1800 ms → flight (CSS 1050 ms) → завершение сцены через 1150 ms после начала flight → Hero photo entrance 1500 ms desktop / 1100 ms mobile → АННА → & → МАКСИМ. От нажатия до смены сцены 2950 ms. Hero hidden/inert до завершения; затем становится доступным и получает фокус main.
4. Mobile: тот же исходный бумажный самолёт, адаптивные размеры письма и траектория в vw/svh, исходный тайминг. Reduced motion: исходный короткий путь около 200 ms, пространственные CSS-анимации отключены.
5. Regression: 13 browser tests / 14 baselines. Отдельные сценарии paper airplane transition 375 и 1440 проверяют folding, настоящий letter-flight, промежуточное состояние и hidden/inert Hero. Существующие CSS-анимации паузятся в детерминированном кадре (flight 350 ms), чтобы сравнить бумажный самолёт. После кадра проверяются завершение сцены, фокус и polished Hero animation. Отдельный reduced-motion тест и свободно проигрываемый normal-motion сценарий проверяют переход без паузы.
