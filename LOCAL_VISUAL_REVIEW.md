# Локальный visual/content pass, 16 октября 2026

Предпросмотр: http://localhost:3100/#dress-code. Правила: http://localhost:3100/venue-rules.
QA использует синтетические данные и локальную PGlite. Production DB, migrations, API, server validation, Amvera и Telegram не менялись; push/deployment не выполнялись.

1. **Женская палитра.** Две отдельные семьи: приглушённые sage/eucalyptus/olive/khaki/moss и сливочное масло → тёплая ваниль → шампань → мягкое золото. Обычный молочный и холодный белый не предлагаются как женская одежда; светлые аксессуары разрешены отдельно.
2. **Мужская палитра.** Оливковый пиджак + молочная рубашка + оливковый галстук/бабочка. Светлая группа off-white/ivory/milk/cream без butter/gold. Для брюк, обуви и ремня есть свобода внутри спокойных светлых, оливковых и тёплых нейтральных.
3. **Границы.** Оливковые swatches #909B7D / #859077 / #788064 / #6F785B / #626B4F. Женские тёплые: #EEE0AE / #E4D3A0 / #D8C58E / #CBBB84 / #B9A674. Мужские светлые: #F7F3EA / #F2ECDE / #EEE5D4 / #E8DECB / #DED3BF. Это визуальные ориентиры диапазона, не требование точного совпадения. Исключены неон, слишком холодные/тёмные зелёные, ледяной белый в женской одежде. Pinterest не открылся из среды; использованы заданные пользователем текстовые ограничения, без самостоятельного расширения.
4. **Помощь Ани.** Над переключателями дружелюбная бумажная заметка, ссылка «напишите Ане» → https://t.me/Selesssta, новая вкладка, noopener noreferrer, gold hover/focus.
5. **Четыре экрана.** Девушки/мужчины × одежда/аксессуары. Смена пола возвращает одежду. Общая геометрия палитр и пояснений сохраняет высоту секции. Текущий directional slide, стрелки, клавиатура и swipe сохранены. Все четыре состояния проверены на 320, 375, 390, 430 и 1440 px; общий responsive suite также проверяет 768 px.
6. **Approved, 16 фото.** Девушки/одежда: светлый шалфей, средний olive, мшистый на границе, butter. Девушки/аксессуары: светлая обувь, жемчуг/белая сумка, тёплое золото, кремовые природные детали. Мужчины/одежда: olive+milk, moss+cream, разные оливковые, тёплые нейтральные брюки. Мужчины/аксессуары: olive tie, bow+beige, warm brown, quiet olive.
7. **Anti, 12 фото.** Девушки/одежда: кислотный зелёный, тёмный холодный зелёный, холодный белый. Девушки/аксессуары: неон, тяжёлый чёрный, ледяной металлик. Мужчины/одежда: неон, яркий синий, спортивно-повседневный образ. Мужчины/аксессуары: кислотные/яркие детали, красно-синий принт, спорт/тяжёлая фурнитура. Все выглядят как реальные качественные вещи для другого повода.
8. **Замена изображений.** Все используемые Dress Code изображения заменены: 28 новых WebP в public/images/dress-lookbook-v2. Built-in imagegen, одна cream atelier сцена, прямой ракурс, мягкий дневной свет, portrait 4:5, 960 px. Точные prompts, source paths и список assets: DRESS_CODE_IMAGES_V2.json. Старые ассеты оставлены как предыдущая версия, в новом lookbook не используются.
9. **Необходимые изображения.** Все 28 слотов заполнены; дополнительных генераций для этого пакета не требуется. Мужской неоновый anti-example отдельно исправлен после визуальной проверки: яркий lime и мужская обувь.
10. **Venue.** Full-width photograph вместо двух соседних колонок, справа полупрозрачная округлая cream плашка с теми же данными и картой. На мобильном плашка у нижнего края фото. Фото автоматически меняется через 5 секунд, crossfade 1400 ms и scale 1.025 → 1; ручное листание даёт 10 секунд паузы. Reduced motion отключает auto и движение.
11. **Fullscreen.** Native dialog, contained photo без crop, close/count, desktop side arrows, ArrowLeft/Right и A/D, Esc, mouse/touch swipe. Background scroll lock, native focus trap и возврат фокуса к фото. Пока dialog открыт, autoplay остановлен. Одно событие меняет один кадр.
12. **Intro keyboard.** Enter/Space на закрытом конверте вызывает существующий openEnvelope, на готовом письме foldLetter. Native buttons не получают второй глобальный запуск. Repeat и modified shortcuts исключены. Полёт и тайминги, Hero entrance и reduced-motion путь сохранены.
13. **RSVP draft.** Versioned sessionStorage: только поля гостя, без cookie/CSRF/session tokens. Восстановление после reload и возврата; несовместимый/повреждённый/чрезмерный draft отбрасывается. После успешного submit удаляется; «Добавить ещё гостя» очищает поля. Черновик дополнительного гостя также переживает reload. Хранилище не обязано быть доступно: отказ storage не ломает форму.
14. **Agreement checkboxes.** «Я согласен соблюдать заданный дресс-код» со ссылкой #dress-code. Новый более заметный «Я согласен соблюдать правила площадки, на которой проводится мероприятие» → /venue-rules в новой вкладке. Оба обязательны на клиенте только для Приду; Не приду сохраняет прежний сценарий. Новый venue consent пока не отправляется в API и не хранится в DB.
15. **Правила для гостей.** Восемь пунктов: уважение; несогласованный огонь/пиротехника; конфетти/осыпания; курение/свои кальяны; парковка и алкоголь за рулём; собаки; исходный список опасных предметов/веществ; бережное отношение к имуществу. Суммы штрафов вторичны. Финал дружелюбный, ссылки Ани и Максима работают с клавиатуры. Текст перенесён из пользовательского задания; исходный файл документа площадки в этом пакете не приложен.
16. **Организаторские условия исключены.** Залог/сроки/возврат; аренда/ранний заезд/окончание/продление и цены; демонтаж/вывоз декора; организация салюта/фаер-шоу/дыма/наземной пиротехники; резиденты/подрядчики/световое оборудование; тревожная кнопка/приезд и стоимость охраны; обязанность заказчика донести правила. Запрет собак не расширен на всех животных; к списку опасных предметов не добавлены категории.
