# Аня & Максим: приглашение и RSVP
Утверждённые первые четыре этапа и публичные секции, серверный RSVP на PostgreSQL, Telegram admin и уведомления. Настройка Stage B: [STAGE_B_DEPLOYMENT.md](STAGE_B_DEPLOYMENT.md).

## Запуск
Node.js 20.9+. `npm install`, затем `npm run dev`. Предпросмотр: http://localhost:3000/. Проверка: `npm run build`.

## Дизайн и контент
- `VISUAL_SYSTEM.md` — утверждённые материалы, палитра, типографика, композиция и motion.
- `src/content/invitation.ts` — первые экраны, имена, дата и время.
- `src/content/calendar.ts` — событие календаря, московский часовой пояс и напоминание за семь дней.
- `src/content/public-sections.ts` — тексты, площадка, дресс-код, программа, подписи формы.
- `src/content/guests.mock.ts` — 22 вымышленных гостя, 11 родных и 11 друзей.
- `STATIONERY_ASSETS.md` — источники, промпты и лицензии временных изображений и шрифтов.
- `src/app/chapters.css` — новые секции; остальные CSS сохраняют первые экраны.

## Напоминание
`/calendar.ics` — статический iCalendar: 17 июля 2027, 16:00 Europe/Moscow (13:00 UTC), название «Свадьба Ани и Максима», VALARM за семь дней. Открытие приложения/импорт и сохранение уведомления зависят от календаря и настроек устройства. Время окончания не выдумано.

## Ограничения прототипа
RSVP сохраняется сервером в PostgreSQL, повторная отправка из той же сессии возвращает существующий ответ. Admin работает только в Telegram по whitelist. PDF пока нет.
Вступление показывается один раз на вкладку, повторный просмотр доступен внизу. sessionStorage содержит только флаг просмотра, имена гостей не записываются в cookies или storage.
Площадка: Марьяж Холл, Марьино, Денисовская, 8. Кнопка карты ищет площадку по полному адресу. Фотографии площадки и образы дресс-кода предоставлены арт-директором. Галерея места: автосмена 5 секунд, пауза 10 секунд после каждого ручного действия; смена кадров горизонтальным свайпом. Дресс-код: горизонтальная полоса с кнопками, клавиатурой, перетаскиванием мышью и touch-прокруткой. Фото гостей — вымышленные placeholder-идентичности.

Production размещён владельцем на Amvera. Build не требует runtime Variables. Amvera запускает start:amvera: APP_ROLE=web применяет migrations и запускает Next.js, APP_ROLE=bot запускает отдельный production long polling worker. Webhook не используется. Инструкция без контейнерного терминала: STAGE_B_DEPLOYMENT.md.



## Перед коммитом
`npm run check:secrets` проверяет рабочие файлы и текущий индекс без вывода значений. После `git add .` выполните `npm run check:secrets -- --staged`, затем `git diff --cached --check` и просмотрите `git diff --cached --stat`. Проверка локальная и эвристическая, неизвестные форматы секретов требуют ручного просмотра. `.gitignore` не исключает уже добавленные в индекс файлы; для такого файла используйте `git rm --cached -- путь`. `.env.example` разрешён только с пустыми значениями или явными заглушками. Реальные credentials нельзя хранить в коде, документах или `NEXT_PUBLIC_*`. Переменные runtime и инструкции по БД указаны в .env.example и STAGE_B_DEPLOYMENT.md.

## Telegram
Безопасная локальная настройка организаторов: [TELEGRAM_DEVELOPMENT.md](TELEGRAM_DEVELOPMENT.md). Команды: `npm run telegram:check`, `npm run telegram:setup`, затем после ручной настройки whitelist `npm run telegram:dev`. Токен только в исключённом из Git `.env.local`, не в frontend.
